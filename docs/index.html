Cài đặt DNS
Hướng dẫn cài đặt:
1. Bấm nút Cài đặt DNS ở trên (bắt buộc dùng Safari)
2. Chọn Cho phép khi Safari hỏi
3. Vào Cài đặt → Đã tải hồ sơ → Cài đặt
4. Vào Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng nhận (nếu có) và bật tin cậy

⚠️ Chỉ mở bằng Safari. Chrome, Zalo, Messenger sẽ không hiện nút “Cho phép”.
